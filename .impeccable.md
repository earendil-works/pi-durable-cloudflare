## Design Context

### Users

Developers inspecting durable AI-agent conversations. They need to follow the conversational sequence while retaining access to tool arguments, progress, results, diagnostics, retries, and other runtime state for debugging.

### Brand Personality

Calm, compact, and technical. The interface should feel trustworthy and legible rather than decorative or chatty.

### Aesthetic Direction

A restrained, light, utilitarian interface that preserves the application's current minimal visual language. Operational detail should sit inline with the transcript, with secondary JSON and diagnostics progressively disclosed. Avoid ornamental effects and avoid turning every event into a prominent card.

### Design Principles

1. Present conversation and execution events in one chronological flow.
2. Replace transient activity with its durable result instead of showing both.
3. Keep debugging detail available, but collapse arguments and raw details by default.
4. Distinguish status with explicit text and structure, never color alone.
5. Preserve keyboard access, semantic HTML, and WCAG AA contrast.
